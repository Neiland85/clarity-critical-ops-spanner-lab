# Contribution Policy

This is a proprietary repository.

Unsolicited code, documentation, architecture, tests or other contributions are
not accepted.

## Prior written agreement required

Before any contribution is submitted, the contributor must have a written
agreement with Clarity Structures Digital S.L. covering:

- confidentiality;
- ownership or assignment of contribution rights;
- warranties of original authorship;
- third-party code restrictions;
- authority to contribute;
- relicensing and commercial exploitation rights.

Opening a pull request, issue or discussion does not create a license,
partnership, employment relationship or obligation to accept the contribution.

## No confidential material

Do not submit:

- personal data;
- customer information;
- credentials or secrets;
- classified or restricted material;
- third-party confidential information;
- code that the contributor is not authorized to provide.

## Security reports

Potential security issues must not be published in a public issue.

Send reports to:

admin@claritystructures.com
