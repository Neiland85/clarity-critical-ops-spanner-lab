# Paquete de derivación interna — Santander

## Objetivo

Conseguir una presentación interna con arquitectura tecnológica, resiliencia operativa, riesgo TIC, integración crítica o innovación aplicada.

No se solicita una compra ni un despliegue.

## Orden de uso

1. Enviar el mensaje de `03_MENSAJES_DERIVACION.md`.
2. Adjuntar `01_NOTA_EJECUTIVA.md`.
3. Adjuntar `02_FICHA_TECNICA.md`.
4. Reservar `04_PRESENTACION_8_DIAPOSITIVAS.md` para la reunión técnica.

## No enviar en la primera aproximación

- repositorio;
- auditoría completa;
- ZIP técnico;
- propuesta económica cerrada;
- contrato de licencia;
- claims de producción, exactly-once o cumplimiento DORA.

## Resultado esperado

Una reunión exploratoria de 45 minutos con:

- sponsor técnico;
- propietario de un caso de uso;
- responsable de resiliencia o riesgo tecnológico.
